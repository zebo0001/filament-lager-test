Spulen

Standort kommt direkt aus den Lagerplätzen — kein manuelles Eintippen mehr. Über „Auf Drucker/ACE“ bzw. „In Drybox“ wird ein freier Platz zugewiesen (Spoolman-Standort wird automatisch aktualisiert). Ist eine Rolle leer, markiert „Rolle leer“ sie in Spoolman als archiviert, gibt den Platz frei und setzt einen Eintrag auf die Einkaufsliste.

Lagerplätze

Geräte anlegen (Drybox, ACE, Drucker, …), bei Bedarf mehrere Reihen pro Ebene angeben (z. B. 2, wenn Spulen hintereinander liegen) und Spulen auf konkrete Plätze legen. Bei Druckern mit ACE-Zuführung kann ein Platz als reserviert markiert werden (bleibt auch bei mehreren gekoppelten ACE-Einheiten über einen Hub an derselben Position). Der Standort wird automatisch zu Spoolman zurückgeschrieben.

Einkaufsliste

Wird automatisch befüllt, wenn eine leere Spule über „Rolle leer“ aus dem System genommen wird. Einträge können hier auch manuell ergänzt oder entfernt werden.
